This is a compact flash interface for the classic ROSCO SBCs.  It is really "old school" because it uses
through hole 74LS logic.  It fits on the 64-pin expansion header of the ROSCO.  Images for the SST EEPROMs will be
provided that support running 68k CP/M on "bare metal", as well as a "bare metal" utility for accessing the compact
flash.
